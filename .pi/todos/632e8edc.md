Completed a styling architecture investigation and implemented foundational refactors:

- Unified runtime theming through `src/theme/index.ts` using NativeWind's color-scheme hook.
- Switched major shared surfaces/layouts and theme-dependent components to the same theme source.
- Strengthened typography defaults by making `Typography` default to the reading serif family.
- Added semantic font utilities (`font-reading`, `font-strong`, `font-display-italic`) and replaced problematic weight utilities in central UI selectors/modals.
- Simplified web font bootstrapping in `src/app/+html.tsx` to avoid conflicting manual `@font-face` declarations.
- Updated key app layouts and shared components (`_layout`s, home, drawer, search, notifications, date picker, external links, liturgical season, selectors) to use centralized theme values.

Validation:

- `npm run check` ✅
- `npm run lint` ✅ with pre-existing project warnings only (no new errors)

Remaining investigation notes for future large refactors:

- Replace remaining ad-hoc inline color styles and repeated card/divider patterns with semantic utilities/components.
- Audit raw `Text` usage and nested typography for a consistent variant API.
- Address existing project lint warnings unrelated to this styling pass.
- Consider a formal design-token export strategy so CSS and TS tokens come from one source of truth.
