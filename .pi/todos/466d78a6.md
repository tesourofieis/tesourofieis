Audit notes after broader comparison:

Patterns identified:

- `Typography` always injects `font-reading text-sepia` (`src/components/typography.tsx`), so any later `font-display`, `font-italic`, or fine-grained color classes may resolve differently on native vs web.
- `text-pretty` is not just typography rhythm — it also adds `py-2 px-3` (`src/global.css`), so using it for compact labels/titles silently changes spacing.
- `bold` also re-applies text color in CSS (`src/global.css`), which can fight later semantic color classes.
- Card radius is not tokenized: most surfaces use `rounded-xl`, but the homepage featured card variant in `src/components/LinkCard.tsx` uses `rounded-2xl`, making it an outlier.

Same/similar patterns elsewhere:

- Tracked uppercase micro-labels:
  - `src/app/index.tsx` day-of-week label
  - `src/app/index.tsx` time section label
  - `src/components/LiturgicalSeason.tsx` "Tempo Litúrgico"
  - `src/components/Headings.tsx` H3-style headings (same visual family, though implemented directly on `Text`)
- `Typography` + `font-display` combinations that may drift on native:
  - `src/components/LiturgicalSeason.tsx`
  - `src/components/LinkCard.tsx` indulgence header
  - `src/components/Search.tsx`
  - `src/components/Notifications.tsx`
  - `src/components/External.tsx`
  - `src/components/PickerModal.tsx`
  - `src/app/_layout.tsx`
- `text-pretty` used in compact UI/card labels where padding can leak into layout:
  - `src/components/LinkCard.tsx`
  - `src/components/Tabs.tsx`
  - `src/components/External.tsx`
  - `src/app/devocionario/novenas.tsx`
